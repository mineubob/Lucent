9/**
10 * Collects the outcome of validating a data payload.
11 *
12 * A Result holds any validation errors (keyed by dotted field path) and the
13 * values produced by validation. Every present field is seeded with its raw
14 * value; constraints that normalize (e.g. {@see \Lucent\Validation\Constraints\Numeric}
15 * casting a numeric string) overwrite it with the transformed value. Values
16 * are stored as nested arrays, so {@see value()} accepts a dotted path
17 * (`user.name`) or a top-level key (`user`). It is returned by
18 * {@see Validator::validate()} and passed to each {@see FieldContext}.
19 *
20 * A Result is **not coroutine-safe**: it is created fresh for every
21 * {@see Validator::validate()} call and must never be shared across
22 * concurrent coroutines (e.g. under Octane/Swoole). The combinators snapshot
23 * and restore its error state during validation, so sharing one instance
24 * across coroutines would corrupt each other's errors.
