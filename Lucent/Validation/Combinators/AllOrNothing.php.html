13/**
14 * A combinator that requires a group of fields to be provided together.
15 *
16 * Either every field in the group is present, or none are. When all are
17 * present, each is validated by its own constraint; when none are present,
18 * the group passes and is left untouched. A partial group (some fields
19 * present, some absent) fails.
20 *
21 * This is useful for a set of related optional fields that must be supplied
22 * as a unit — for example a `billing_address` group where all sub-fields are
23 * required together.
24 *
25 * ```php
26 * AllOrNothing::of([
27 *     'street' => new Required(),
28 *     'city'   => new Required(),
