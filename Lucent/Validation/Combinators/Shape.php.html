13/**
14 * A combinator that validates an array value as an object or a tuple.
15 *
16 * Shape has two forms, selected by factory:
17 *
18 * - {@see object()} validates a map of named sub-fields, each with its own
19 *   constraint. Sub-field errors and values are namespaced under the parent
20 *   field's dotted path (e.g. `user.name`).
21 * - {@see tuple()} validates a fixed-length, positional list where each
22 *   position has its own constraint. Element errors and values are namespaced
23 *   by index (e.g. `pair.0`).
24 *
25 * ```php
26 * Shape::object(['name' => new Required(), 'email' => new Email()]);
