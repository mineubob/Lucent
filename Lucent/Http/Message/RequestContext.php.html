7/**
8 * A mutable, request-scoped context bag.
9 *
10 * Holds user-written state that rules, middleware, and controllers share
11 * during a single request. Unlike the PSR-7 request (which is immutable),
12 * this object is mutated in place, so a write made anywhere is visible
13 * everywhere that holds the same instance.
14 *
15 * One instance is created per request and attached to the request as the
16 * 'context' attribute (see {@see ServerRequest::capture()} and
17 * {@see ServerRequest::create()}). Because the request is passed by value
18 * but the bag is a shared object, every copy of the request points at the
19 * same bag — no by-reference threading is needed.
20 */
