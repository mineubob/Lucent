10/**
11 * PSR-7 stream implementation backed by a callable, providing a lazy
12 * one-shot body.
13 *
14 * The callback is invoked once on the first read/getContents/__toString call.
15 * Subsequent calls return an empty string. The callback can use echo/printf
16 * (captured via output buffering) or return a string.
17 *
18 * This is NOT incremental streaming — the entire output is buffered in memory
19 * on first read. Its value is deferred execution: expensive computation or
20 * external calls only run if the body is actually consumed. For true
