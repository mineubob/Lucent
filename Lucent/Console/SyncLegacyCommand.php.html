16/**
17 * The `sync:legacy` command — a one-time table-name migration for
18 * databases created by the pre-Radiant Lucent ORM.
19 *
20 * Old Lucent named tables after the model's short class name (e.g.
21 * `TestUser`); Radiant defaults to the snake-cased plural (`test_users`).
22 * For each discovered model, when the old-style table exists and the
23 * Radiant name does not, the table is renamed — data travels with the
24 * rename. No column or data conversion is performed (old DDL remains
25 * valid under Radiant).
26 *
27 * Output is echoed progressively (visible live in a terminal); in captured
28 * mode (tests) the ob_start wrapper in executeConsoleCommand() still
29 * collects it, so the return value is always ''.
30 *
31 * Idempotent: a second run finds nothing to rename. Deprecated — will be
32 * removed in a future release.
33 *
34 * --dry-run displays the rename plan and exits without applying anything.
35 */
